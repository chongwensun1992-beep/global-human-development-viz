# Code of Conduct

## Our Pledge
We are committed to creating a welcoming, inclusive, and harassment-free environment for everyone involved in this project, regardless of background, identity, or experience level.

We value collaboration, respect, and constructive communication, and we expect all participants to contribute in a professional and considerate manner.

## Expected Behavior
Participants in this project are expected to:
- Be respectful and considerate in speech and actions.
- Use inclusive language and show empathy toward others.
- Provide constructive feedback and accept feedback gracefully.
- Collaborate in good faith and support team members.
- Respect differing viewpoints, experiences, and skill levels.

## Unacceptable Behavior
Unacceptable behavior includes, but is not limited to:
- Harassment, discrimination, or exclusionary behavior.
- Offensive comments related to gender, race, ethnicity, religion, disability, or other personal characteristics.
- Personal attacks, insults, or deliberate intimidation.
- Disruptive behavior that negatively impacts collaboration.

## Reporting Issues
If you experience or witness unacceptable behavior, please report it to one of the project maintainers or course instructors as soon as possible.

All reports will be handled confidentially and respectfully.

## Enforcement
Project maintainers and instructors are responsible for enforcing this Code of Conduct. They may take appropriate action in response to violations, including requesting changes in behavior or restricting participation if necessary.

## Scope
This Code of Conduct applies to all project spaces, including GitHub repositories, issues, pull requests, meetings, and any communication channels related to the project.
