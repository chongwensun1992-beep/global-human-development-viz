# Global Human Development Explorer

An interactive dashboard for exploring global human development indicators across countries and time.

## Overview

The Global Human Development Explorer is an interactive data visualization dashboard designed to support exploration and communication of global development trends. The app allows users to compare countries, examine changes over time, and investigate relationships between key human development indicators such as education, health, and overall development outcomes.

The dashboard is intended for policy analysts, researchers, students, and members of the public who are interested in understanding global inequality and development progress. By combining multiple coordinated visualizations with flexible filtering options, the app makes it easier to move beyond static tables and reports toward interactive, exploratory analysis.

Users can select different indicators and years, filter countries by region or development group, and compare trends for multiple countries simultaneously. A dedicated scatter plot enables users to explore relationships between two indicators, while a trend view highlights long-term changes over time.

## Key Features

- Interactive bar chart ranking countries by a selected development indicator  
- Scatter plot for exploring relationships between two indicators  
- Line chart showing time trends for selected countries  
- Filters for year, region, and human development group  
- Collapsible sidebar for a clean, focused viewing experience  
- Contextual legend and help panel explaining current selections  

## Data Source

The dashboard uses publicly available country-level human development data derived from the United Nations Development Programme (UNDP). Indicators include Human Development Index (HDI), Expected Years of Schooling, and Life Expectancy at Birth, measured annually across multiple decades.
